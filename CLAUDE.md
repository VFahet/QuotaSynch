## Agent skills

Un petit programme Windows, pour moi et en open source sur GitHub, qui envoie un message minimal à Claude Code à des heures choisies pour que mes fenêtres de quota de 5 h démarrent à heures fixes, et qui relève le pourcentage de quota pour analyser l'usage. Il doit rester très léger.

Toute modification du code passe par `/patch` ou `/build`. Lire `docs/agents/sdlc.md` avant d'écrire, et `docs/agents/codebase-map.md` avant d'explorer.

Tout commit commence par son type — `feat`, `fix`, `refactor`, `perf`, `test`, `docs`, `style`, `ci`, `chore`, `revert` — selon la section Commits de `docs/agents/sdlc.md`.
